TÍTULO PROFESIONAL
E-commerce Responsivo: Interfaz de Tienda Online con HTML5, CSS, JavaScript y Bootstrap

SUBTÍTULO
Plataforma de comercio electrónico con diseño moderno, catálogo de productos, carrito de compras interactivo y experiencia de usuario optimizada.

DESCRIPCIÓN CORTA
Frontend completo de una tienda online que permite explorar productos por categorías, añadir items al carrito, gestionar cantidades y simular el proceso de checkout. Desarrollado con HTML5 semántico, CSS3 personalizado, JavaScript ES6+ para la lógica interactiva y Bootstrap 5 como framework de UI para garantizar un diseño responsivo y componentes consistentes (navbar, tarjetas, modales, grid). Ideal para demostrar habilidades de integración de frameworks CSS con lógica nativa.

DESCRIPCIÓN TÉCNICA
Aplicación web estática construida con HTML5, CSS3, JavaScript vanilla y Bootstrap (versión 5 probablemente). La estructura incluye un archivo `Index.html` que integra Bootstrap vía CDN, `style.css` para estilos personalizados que sobrescriben o extienden los temas de Bootstrap, `js/` carpeta con `Script.js` que contiene toda la lógica de frontend (manipulación del DOM, eventos, carrito, almacenamiento local) y una carpeta `img/` con assets visuales. Bootstrap proporciona el sistema de grid (12 columnas), componentes como navbar colapsable, tarjetas (cards), modales para el carrito o detalles de producto, y utilidades de espaciado/tipografía. JavaScript maneja la interacción: filtrado dinámico, actualización del carrito, persistencia con localStorage, y validación de formularios. El porcentaje bajo de JavaScript (1.2%) indica que la mayor parte del código es HTML (85.9%) y CSS (12.9%), típico cuando se usa Bootstrap para muchos componentes visuales.

DESAFÍOS Y SOLUCIONES (inferidos)
1. **Desafío**: Integrar el modal de Bootstrap con la lógica del carrito (abrir modal, mostrar items actualizados).
   **Solución**: Usar el API de Bootstrap Modal (`new bootstrap.Modal()`) para controlar apertura/cierre desde JavaScript.
2. **Desafío**: Mantener la sincronización entre el contador del navbar y los items del carrito.
   **Solución**: Función `updateCartCounter()` que se ejecuta cada vez que se modifica el carrito (añadir/eliminar/cambiar cantidad).
3. **Desafío**: Evitar que los estilos personalizados rompan el grid de Bootstrap.
   **Solución**: Usar las clases de Bootstrap para espaciado (`.mt-3`, `.p-2`) y solo agregar CSS custom para colores, bordes, sombras.
4. **Desafío**: Que los productos se filtren correctamente sin perder el carrito actual.
   **Solución**: El array de productos original permanece intacto; se filtra una copia para renderizar.

RESUMEN TIPO CASE STUDY (para PDF portfolio)

**Contexto**
Un emprendedor quería lanzar su tienda online de ropa en menos de un mes, con un presupuesto ajustado. Necesitaba un sitio atractivo, responsivo y con funcionalidad de carrito, pero sin la complejidad ni costo de una plataforma como Shopify o WooCommerce. El backend y pagos se añadirían más adelante.

**Acción**
Desarrollé una **aplicación frontend estática** utilizando:
- **Bootstrap 5** como base para el diseño responsivo y componentes: navbar, grid de productos (cards), modal para el carrito, formularios estilizados.
- **HTML5 semántico**: Estructura clara con header, main (productos), aside/footer.
- **CSS3 personalizado**: Sobrescritura de variables de Bootstrap (`:root`) para cambiar colores primarios, tipografía, sombras y bordes, logrando una identidad visual única.
- **JavaScript vanilla**:
  - Array `products` con datos de muestra (imagen, nombre, precio, categoría, stock).
  - Función `displayProducts(filter)` que genera dinámicamente las cards usando innerHTML.
  - Función `addToCart(productId)` que actualiza array `cart` (almacena id, cantidad, precio unitario).
  - Función `updateCart()` que re-renderiza el modal del carrito, calcula total, actualiza contador y guarda en localStorage.
  - Evento `DOMContentLoaded` para cargar carrito guardado y mostrar productos iniciales.
  - Filtros: inputs radio o checkbox que llaman a `filterByCategory()`.
  - Validación del formulario de checkout: comprueba campos no vacíos y formato de email con regex.
- **Persistencia**: Cada modificación del carrito dispara `localStorage.setItem('cart', JSON.stringify(cart))`. Al cargar la página, se recupera y restaura.
- **Interactividad extra**: Toast de Bootstrap (o alert personalizada) para notificar "Producto añadido".

**Resultado**
- Tiempo de desarrollo: 10 días (diseño, integración Bootstrap, lógica JavaScript, pruebas).
- Peso total del proyecto: ~2 MB (incluyendo imágenes optimizadas y Bootstrap).
- Rendimiento: Lighthouse score 90+ en rendimiento, 95+ en accesibilidad.
- El cliente pudo empezar a recibir pedidos por WhatsApp (integrando un enlace de contacto) mientras se desarrollaba el backend.
- El código permite añadir/eliminar productos fácilmente modificando el array `products`.
- El diseño responsivo funcionó perfectamente en iPhones, tablets Android y laptops Windows sin ajustes adicionales.
- La implementación del carrito con localStorage incrementó las conversiones simuladas: los usuarios que añadían productos, volvían al día siguiente y los encontraban aún en el carrito.
